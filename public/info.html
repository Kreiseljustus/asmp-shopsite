Data Collection Info

This page explains what data this site stores and how it is used.

Collected Data

  • Shop submissions: owner, item, price, amount, position, dimension, action.
  • Waystone submissions: owner, waystone name, position, dimension.
  • Statistics submissions: username, optional UUID, and Minecraft statistics JSON.
  • News and graph values configured by Criisel.
  • Basic page visit counts per day and page type.

How It Is Used

  • Shops/waystones are shown on public map/list pages.
  • Statistics are used to build leaderboard categories.
  • Visit counts are used for basic traffic tracking.
  • Ignored usernames are used for moderation and filtering.

What Is Not Collected

  • No passwords or authentication tokens.
  • No email addresses or private account details.
  • No client mod IP history in site data files. (IP adresses that access the site are retained for up to two weeks)

Data Management

  • Admins can replace category config and ignored-user lists via API.
  • If a username is ignored, their shops, waystones, and stats are removed and blocked.
  • Contributed data may be updated or removed when needed.

If you have any concerns please reach out to Criisel on discord!
